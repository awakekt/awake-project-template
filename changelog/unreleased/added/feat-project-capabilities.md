- **A game's own code is linked from its project's manifest.** The `plugins` entries in the bundled project's `awake.project.json` that name a `capabilityClass` are generated into `projectCapabilities`, which `loadGame` passes to `loadProject`. An entry with an `artifact` also adds that library. `app/shared` applies the Kotlin serialization plugin, which a game's scene components need. A JVM test loads the bundled project as the app does.
