- **The web player runs the Core release it is built for.** Left blank, the "Web player release" workflow paired Core with the next patch's WebGPU snapshot. That snapshot is Core main after the release, so it moved part of Core up on the web build only, and it does not exist until another Core commit lands. The workflow now uses `<core>-SNAPSHOT`, the WebGPU build of that release, and fails when that build or the web app's resolved classpath names any other Core. A scheduled run waits for the next day instead. The release notes name the timestamped WebGPU build, and the template pins WebGPU `0.8.3-SNAPSHOT` for Core `0.8.3`.
